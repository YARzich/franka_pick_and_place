**Слой:** [[Задача переноса.canvas|Задача переноса]] · ⚙️ часть сервера · 📦 `manipulation_moveit` (+ выбор захвата `franka_motion`)

## Что делает

Единственная боевая стратегия. Раскладывает один шаг переноса на 13 маленьких действий:

открыть пальцы → предзахват → подход → **сжать** → прикрепить в сцене → поднять → подлёт к цели → поставить → **отпустить** → открепить в сцене → выдержка → отход → (домой, если просили).

## Ключевые механики

- **Выбор захвата** делает мини-конвейер MoveIt Task Constructor: на **локальной копии** сцены перебираются хваты вокруг кубика (шаг 30°, до 8 достижимых по обратной кинематике решений), берётся лучший. Предзахват — отступ 10 см против направления подхода.
- **Куда ставить:** позиция из цели, ориентация из наблюдения; точка кисти при постановке = цель ⊗ (наблюдение⁻¹ · захват) — рука повторяет ровно тот же хват относительно кубика, что был при взятии.
- **Дисциплина перед каждым действием:** допуск готовности + точная ревалидация аренды/ревизии сцены. Если робот успел «уехать» от стартового состояния плана — траектория выбрасывается и планируется заново (до 3 раз).
- **Восстановление при ошибке** — по политике шага: ничего / замереть / отойти вверх / отойти и домой. При неопределённой сцене или неизвестной позе движение восстановления **запрещено** — лучше честно замереть, чем «наугад». При отмене восстановление не выполняется вовсе.

## Что можно крутить

- Профиль захвата (шаг перебора, число решений, отступ предзахвата) — yaml.
- Политика восстановления — на каждый шаг заказа отдельно.

> [!info]- 🔧 Настоящие имена
> - `manipulation_moveit/src/pick_lift_place_strategy.cpp` (13 шагов, `kMaximumStartStatePlans = 3`); реестр: единственный id `pick_lift_place`.
> - Захват: `franka_motion/src/workflow_v2/mtc_grasp_provider.cpp` (FixedState → GenerateGraspPose → ComputeIK), профили `config/tasks/mtc_grasp_profiles.yaml` (`panda_top_down_cube`: angle_delta ≈30°, max_solutions 8, pregrasp 0.1 м).
> - Политики восстановления: `RECOVERY_NONE / SAFE_STOP / RETREAT / RETREAT_AND_HOME`.
