# Участие в проекте

Проект находится до версии 1.0 и имеет статус `candidate`. Перед изменением
прочитай README затрагиваемого пакета, [AGENTS.md](AGENTS.md) и
[правила совместимости](docs/CHANGE_CONTROL.md).

Одна правка должна решать одну понятную задачу. В описании изменения укажи
проблему, новое поведение, выполненные проверки и оставшиеся ограничения.
Смена ROS wire-контракта или ответственности пакета требует явной миграции.

## Проверки

1. Установи зависимости и собери затронутые пакеты вместе с зависимостями по
   [INSTALL.md](INSTALL.md), без подключённого старого overlay.
2. Запусти зарегистрированные `colcon test` для затронутых пакетов. При изменении
   публичного API проверь также его потребителей.
3. При изменении границ, зависимостей или контрактов запусти из корня семейства
   `python3 scripts/check_architecture.py`. Проверка не требует ROS или GPU.
4. Для изменения движения, отмены или владения процессами выбери соответствующий
   runtime-профиль из `franka_motion`, сохрани результат и сведения об окружении.
   Никогда не завершай чужие ROS/Gazebo-процессы для подготовки теста.

Для автономных [инструментов обучения](training/README.md) дополнительно запусти
`PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python3 -B -m pytest -q -p no:cacheprovider training/tests`.
Эти тесты требуют `pytest` и `PyYAML`, не запускают обучение и не требуют GPU.

Проверки исходников, сборки и пакетных тестов выполняются локально на Jazzy по
[INSTALL.md](INSTALL.md). Isaac Sim, GPU inference и реальное оборудование
требуют отдельной среды; пакетные проверки не подтверждают их работу.
Для диагностических scripts в `.agents/skills` используй явные пути окружений;
инструкции доступны и без запуска Codex.

В исходники не включаются build/install/log, локальные IDE-настройки, данные
пользователя и секреты. Для стороннего ресурса сохраняются происхождение,
исходная лицензия и относящиеся к нему уведомления. Проверенные веса моделей
не удаляются ради уменьшения репозитория без сохранения способа их получения.
